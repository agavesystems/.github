# agavesystems/.github

Las plantillas y archivos de gobierno por defecto de los repos de `agavesystems`: formularios de issue, plantilla de PR, `CONTRIBUTING.md`, `SECURITY.md` y `SUPPORT.md`. GitHub los aplica a todo repo de la org que no traiga los suyos.

## Por qué este repo es público

GitHub solo aplica los archivos por defecto de una org si el repo `.github` es público. Por eso aquí no hay nada del negocio: ni clientes, ni código, ni infraestructura, ni nombres de servicios internos. Solo cómo se abre un issue y cómo se manda un cambio.

Si algo de aquí necesita un dato privado, ese dato no va aquí. Se liga a un repo privado.

## Cómo se cambia

Por PR a este repo. Un repo que necesite algo distinto pone su propia `.github/ISSUE_TEMPLATE/`, y eso reemplaza **todas** las plantillas de issue por defecto en ese repo, no solo la que cambia.
